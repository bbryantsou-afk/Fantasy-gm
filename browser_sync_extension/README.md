# Fantasy GM 私人聯盟同步（Chrome）

解壓縮後在 chrome://extensions 開啟開發人員模式 → 載入未封裝項目 → 選擇此資料夾。
在同一瀏覽器登入 Yahoo，再開啟 Fantasy GM 的「聯盟同步」。
首次確認隊伍配對。之後按同步即可更新所選日期，歷史日期不改今天名單。

只讀取 basketball.fantasysports.yahoo.com 的聯盟／陣容頁面；不操作加退人、先發、交易。
不讀取 cookies、不索取帳密、不呼叫 AI。需自行確認資料來源允許此用途。

Chrome 開啟自動檢查時，每 30 分鐘保存今天快照；網站開著每分鐘檢查已保存資料。
登出、驗證、頁面改版或隊伍資料不完整時停止套用，保留舊資料。關閉瀏覽器不能保證執行。
最多保留最近 14 個不同日期，保存在 chrome.storage.local，未上傳公共 GitHub。
需要長期保存時，請下載 App 完整同步備份。移除擴充功能會移除此瀏覽器的資料。
新版本更新：重新解壓縮並替換資料夾，在擴充功能頁按重新載入，再重新整理 App。
